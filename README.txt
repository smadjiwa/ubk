CARA DEPLOY
1. Cipta repository GitHub baharu, repository sedia ada: ubk
2. Upload SEMUA kandungan folder ini ke root repository (bukan folder ZIP).
3. Pastikan index.html berada di root.
4. Buka Settings > Pages.
5. Pada Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), kemudian Save.
7. Tunggu sehingga GitHub Pages memberikan URL https://smadjiwa.github.io/ubk/

CARA INSTALL
- Android: buka URL GitHub Pages menggunakan Chrome > menu ⋮ > Install app / Add to Home screen.
- iPhone: buka URL menggunakan Safari > Share > Add to Home Screen.

NOTA
- Launcher boleh dicache dan dipaparkan offline.
- Dashboard Google Apps Script memerlukan internet dan dibuka secara terus selepas butang BUKA DASHBOARD ditekan.
- PWA tidak membungkus laman GAS di dalam iframe. Bergantung pada browser/peranti, pautan silang domain mungkin dibuka dalam tab/browser luar.
- Pastikan akses deployment GAS diberikan kepada pengguna sasaran (contohnya Anyone atau pilihan akses yang sesuai dengan polisi organisasi).
